# TravonetWG Android

Современный клиент для Android на базе ядра **TravonetWG** с поддержкой протоколов **WireGuard** и **AmneziaWG**, встроенным механизмом десинхронизации DPI / ТСПУ в пространстве пользователя (userspace) и прямой интеграцией с Cloudflare WARP.

Приложение работает **без прав суперпользователя (root)**, не требует сторонних прокси-серверов и не передает приватные ключи во внешние сервисы.

---

## Возможности

- **Поддержка AmneziaWG и ссылок `vpn://`:**
  - Прямой импорт ссылок Amnezia (`vpn://`) из буфера обмена или диалога добавления с автоматической распаковкой Qt `qCompress` (zlib) и извлечением параметров.
  - Поддержка параметров обфускации AmneziaWG (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`–`H4`) в конфигурациях `.conf`.
- **Поддержка стандартного WireGuard:**
  - Импорт классических файлов конфигураций WireGuard (`.conf`).
- **Генератор профилей Cloudflare WARP:**
  - Встроенная генерация WARP-профилей с поддержкой отказоустойчивых релеев регистрации (включая работу в условиях блокировок эндпоинтов Cloudflare).
- **Два режима работы:**
  - **VPN (системный TUN):** Стандартный туннель для всех приложений операционной системы.
  - **SOCKS5 Inbound (127.0.0.1:1080):** Локальный прокси без системного разрешения `VpnService` (Zero-Permission режим).
- **Активный обход DPI (Userspace Evasion Engine):**
  - Обход блокировок ТСПУ на уровне непривилегированных UDP-сокетов: отправка мусора (`junk`), имитация протоколов (`mimic(quic)`, `mimic(stun)`), фейковые пакеты рукопожатия (`fake_udp`) с динамическим контролем TTL и микропаузы (`sleep`).
  - Проверенные пресеты для мобильных сетей (LTE / 5G) и Wi-Fi.
- **Управление подключением и диагностика:**
  - Возможность принудительного прерывания ядра прямо во время статуса подключения («Подключение...»).
  - Встроенный тест доступности (HTTP 204 Ping).
  - Отображение статуса Handshake, счётчиков входящего/исходящего трафика в реальном времени.

## Требования

- **ОС:** Android 9.0 (API 28) или новее.
- **Поддерживаемые архитектуры (ABI):**
  - `arm64-v8a` (современные 64-битные смартфоны)
  - `armeabi-v7a` (32-битные устройства)
  - `x86_64` (эмуляторы и планшеты x86_64)
  - `x86` (32-битные эмуляторы x86)

---

## Установка

1. Перейдите в раздел [Релизы (Releases)](https://github.com/SudoNeko68/TravonetWG-Android/releases).
2. Скачайте нужный APK:
   - **`app-arm64-v8a-release.apk`** — рекомендуется для подавляющего большинства смартфонов.
   - **`app-universal-release.apk`** — универсальный пакет со всеми библиотеками.
   - **`app-armeabi-v7a-release.apk`** — для старых 32-битных устройств.
   - **`app-x86_64-release.apk`** / **`app-x86-release.apk`** — для эмуляторов Android.
3. Разрешите установку из неизвестных источников и установите файл.

---

## Импорт конфигураций

1. **Из буфера обмена:**
   - Скопируйте ссылку `vpn://...` или текст файла `.conf` в буфер обмена.
   - В приложении нажмите кнопку **«Из буфера»** — профиль будет автоматически распознан и добавлен в каталог.
2. **Вручную / QR-код / Файл:**
   - Нажмите **«Создать вручную»** или кнопку **«+»** в правом верхнем углу, вставьте конфигурацию или ссылку `vpn://`.
3. **Генерация WARP:**
   - Нажмите кнопку **«Сгенерировать WARP (Cloudflare)»** для мгновенного создания анонимного профиля.

## Пресеты обхода DPI

В приложении доступны готовые стратегии обхода ТСПУ:
- **Мобильная сеть / Wi-Fi (Рекомендуемая):** Базовая проверенная последовательность для сотовых сетей (LTE/5G) и Wi-Fi:
  ```text
  junk(64) -> mimic(quic) -> mimic(stun) -> junk(64) -> fake_udp(148, corrupt=true) -> sleep(15ms)
  ```
- **Junk + QUIC/STUN + junk:** Облегчённый вариант без фейкового хэндшейка.
- **Junk + QUIC/STUN + fake:** Вариант для провайдеров, блокирующих повторный шум.
- **Двойной pre-junk:** Для жестких условий фильтрации.
- **Чистый WireGuard:** Работа без модификации пакетов (для незаблокированных серверов).

## Сборка из исходного кода

Для сборки проекта требуются **JDK 17+**, **Android SDK** и **Android NDK**:

1. Клонирование репозитория:
   ```bash
   git clone https://github.com/SudoNeko68/TravonetWG-Android.git
   cd TravonetWG-Android
   ```
2. Сборка Debug-версии:
   ```bash
   ./gradlew assembleDebug
   ```
3. Сборка Release-версии:
   ```bash
   ./gradlew assembleRelease
   ```
Готовые файлы APK создаются в каталоге `app/build/outputs/apk/release/`.

## Проверка контрольных сумм SHA-256

Контрольные суммы для каждого релиза публикуются в файле `SHA256SUMS.txt`.

Проверка в Linux / macOS:
```bash
sha256sum -c SHA256SUMS.txt
```

Проверка в Windows (PowerShell):
```powershell
Get-FileHash .\app-arm64-v8a-release.apk -Algorithm SHA256
```
